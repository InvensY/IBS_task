## Как запустить

npm install
npm run dev

## Стек

- Vite + React + TypeScript
- react-router-dom (BrowserRouter, useSearchParams)
- CSS (без UI-библиотек)
- Oxlint + Prettier

## Что реализовано

- Список карточек (картинка, имя, статус, вид)
- Поиск по имени (по Enter)
- Фильтр по статусу (alive/dead/unknown)
- Пагинация с переходом на первую страницу при смене фильтра
- Состояния: загрузка / «ничего не найдено» / ошибка запроса
- Адаптив (мобилка + десктоп)
- Поиск и фильтр сохраняются в URL (?name=...&status=...&page=...)
- Запрос уходит не на каждую букву (поиск по Enter)
- Oxlint + Prettier
